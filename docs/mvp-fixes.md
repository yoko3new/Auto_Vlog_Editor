## 本轮变化

| 问题 | 当前处理 |
| --- | --- |
| 中间报错后重新进入 CLI / 重新生成 | CLI 交互失败后可直接重试；无参数启动持续会话。网页失败任务显示 Retry。服务端保存原请求和任务类型，重试编辑不会变成重新生成 |
| 成功步骤反复调用 | 画面和语音分别按源文件散列、模型与配置缓存；渲染失败保留剪辑计划和已完成片段。重试沿用同一请求，成功前保持旧版本可播放 |
| 中文交互 | CLI 启动时选择中文或英文，支持中文项目名和创作方向；也可指定 `--language zh/en`。网页提供中文/English 切换并记住选择 |
| 语音准确度差 | 将画面分析和语音识别拆开。语音从原素材单独提取 PCM 音频，使用 Gemini 专用转写接口；不再依赖有损代理视频的语音结果 |
| 字幕左右裁切 / 尾句丢失 | 按实际视频宽高和字体测量换行，过长时缩小字号，保留全部行；横竖屏均检查。缺字体或实在放不下时明确报错 |
| 自动硬件编码中途报错 | 选择 VideoToolbox 前检查能否实际创建编码会话，不可用时使用软件编码 |
| 5 秒以下不能分析？ | 没有该输入门槛。显式输出目标现为 1–1800 秒（时长/模式更新见[剪辑模式](editing-modes.md)）；真实目录 21 段中有 6 段小于 5 秒，最短 2.4 秒。该短素材已完成真实 Gemini 分析、转写与导出 |

原有 `reviews/` 不能直接作为新流程的有效识别缓存：第一次使用新流程会重新分析和转写，原成功视频继续保留。模型、语音语言或 thinking 配置变化会使相关缓存失效。AI 失败不会静默切模型、丢字幕或以 mock 充当成功。

## Gemini 模型与准确度

2026-10-10 核对官方文档，最新通用稳定模型为 [Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)，模型 ID `gemini-3.8-flash`。它支持视频、图片、音频与结构化输出，作为本轮画面理解和剪辑计划的默认选择；thinking 显式设为 `medium`，可用 `VLOGII_THINKING` 调整。

语音选择 [Gemini 3.5 Transcribe](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-transcribe)，模型 ID `gemini-3.5-transcribe`。它支持中英文与混合语言、自动语言检测和词时间戳，**不支持 thinking**。本项目需要字幕时序，采用逐字忠实转写和词时间戳；官方同时说明启用时间戳可能降低文本准确度，不能预先宣称它在本素材上一定更准。

旧默认 `gemini-3-flash-preview` 同时处理画面与有损代理音频，未显式设置 thinking。因此准确度问题不能仅归因于 effort 或模型能力。还需对照原音、噪声/口音、中英混说、提示词及字幕时间映射。下一轮用人工逐句标注测中文字错误率、英文词错误率、漏句及时间偏移，才能判断实际收益。

配置见 [.env.example](../.env.example)：`VLOGII_MODEL` 控制画面/规划，`VLOGII_SPEECH_MODEL` 控制语音，`VLOGII_SPEECH_LANGUAGE=auto` 保持混合语言检测。明确知道语言时可填官方 BCP-47 代码，例如 `cmn-Hans-CN` 或 `en-US`。界面语言与素材语音语言是独立选项。

专用转写使用 [Interactions REST 接口](https://ai.google.dev/gemini-api/docs/transcribe)，继续使用同一 `GEMINI_API_KEY`。当前锁定 SDK 尚无专用 transcription_config 类型，因此用 httpx 请求该接口；账号可用性需真实验证。若账号暂不支持，可显式将 `VLOGII_SPEECH_MODEL` 设为可用的通用 Gemini 模型走独立音频转写，不自动降级。

画面理解还受采样影响：[官方视频说明](https://ai.google.dev/gemini-api/docs/video-understanding)默认静态模式约每秒一帧。代理文件为 12 fps 不等于模型看了每秒 12 帧；快速动作漏识别需先验证输入采样，再比较 thinking 或模型。

## 用户需要输入什么，怎样迭代

首次生成只必须选择素材；项目名有默认值，目标时长可留空按模式决定（新规则见[剪辑模式](editing-modes.md)），画幅/色彩也有默认值。创作方向可留空，不要求用户第一次写完整剪辑脚本、每段描述、字幕或标题。可选描述只表达偏好，例如“保留早餐和散步，中文原声，按时间顺序”。

两类后续操作分开处理：

- **失败重试**：点 Retry，沿用原请求并复用成功工作，不再要求重填文字。CLI 退出后也可执行 `vlogii retry 项目名`；生成和编辑请求分别保存。
- **成片不满意**：只填想改的字段。当前支持标题、暖度、按素材 ID 排除；生成新版本并可撤销。修改创作方向后“生成新版本”会重新规划，复用未变的素材分析；它仍使用原始导入集，不自动继承上一版本的排除。

已实现中英文时间范围删除/调速和生成模式/时长的常见表达；任意自然语言修改解析器尚未实现，详见[剪辑模式](editing-modes.md)。本轮不把“自动剪辑方向输入”写成“已有自然语言修改”。后续设计应接收短增量指令，如“删掉做饭那段、标题改成周末”；后端结合当前成功版本、原偏好与素材描述转成受控操作，只在指代不明确时让用户选候选。保存修改摘要和版本，用户无需重述全部需求，失败保留旧片。BGM、卡点和成片风格等美化功能留到下一步。

## 本轮实际证据

- Python：44 个测试通过、0 跳过；包括真实 FFmpeg、分段续跑、画面/语音缓存、生成/编辑 Retry、重启恢复、中文 CLI、转写 HTTP 结构及边界。一个上游 Starlette/httpx 弃用提示。
- 私人真实素材：同一段 2.4 秒素材截取 2 秒，输出 720×1280 和 1280×720，均为 30 fps、SDR/H.264/AAC，完整解码通过；长中英字幕完整显示已目视确认。
- 浏览器：中文/English 切换、失败编辑 Retry、成功新版本及旧版本保留已验证。该任务为人为设置的失败编辑，无 AI 调用；不算真实 Gemini 验收。
- Gemini 转写接口用 HTTP 替身验证请求/时间戳/重试。用户随后配置本地密钥，一段 2.4 秒素材真实完成 Gemini 3.8 Flash 画面分析、3.5 Transcribe 转写、规划与导出，得到 2 条字幕，耗时约 23.55 秒。只有一次小样集成结果，未测人工对照准确率、账单费用或负载性能。
