2026-10-10 用户确定的产品方向：聚焦校园、留学、通勤、做饭等生活类短 vlog。参考 [Day In My Life Shorts](https://www.youtube.com/shorts/um2oBpliDbk) 的结构和用户描述；已打开页面并播放，未逐帧测量参考视频切点。下面的秒数是本项目可调整的设计参数，不宣称与参考逐帧一致。

## 默认作品结构

1. **吸引人的封面**：选择清楚、有生活感的真实画面，标题必须包含贴画或艺术字体的视觉设计，保证手机上能读。封面不是只叠普通字幕；主题由素材和用户决定，不编造日期、地点或经历。
2. **开头闪切**：几个代表性镜头一闪而过，用来预告当天内容。当前默认约 5 秒、每镜头最多约 0.5 秒，可选 0.25 / 0.35 / 0.5 / 0.8 秒。镜头停留与素材播放倍速是两个独立设置；短镜头默认静音，避免截断人声，也不叠难以读完的口播字幕；原声回到正文后保留。
3. **正文**：回到能理解的叙事节奏，保留口播或重要环境声，以简单字幕为基础，少量时间标注、关键词和轻特效辅助。不要把正文也全剪成闪切；有意义的片段可以保持原速，走路、通勤、准备过程可按区间加速。
4. **自然结束**：保留适合收尾的真实片段，避免为了固定长度重复素材。

Shorts 是默认创作形式，不强制把所有素材压缩到 30 秒；已有时长、保留比例和完整保留选项继续可用。开头与正文可以使用不同节奏和速度。

## 后期改进：个人风格库

用户希望在自然语言调整过程中形成一份可读、可复用的风格文档，满意后选择保存到自己的风格库，下次导入以减少重复设置。这是后期需求，本轮只记录设计，不实现保存、导入或参考视频提取。

### 使用流程

1. **形成草稿**：从用户描述、已应用的剪辑设置和参考风格整理风格文档；参考视频提取的未知或推测项要标明，供用户查看和修改。
2. **随剪辑迭代**：用户说“开头慢一点”“快剪静音”“字幕简单些”时，更新风格草稿并预览对应成片。失败、撤销或尚未应用的调整不自动成为保存偏好。
3. **选择保存**：满意后命名并保存，关联对应的成功成片版本。用户明确选择新建风格或更新已有风格；不自动把每次尝试写进个人库。
4. **下次导入**：选择自己的风格，再提供新素材、可选主题和本次调整。导入后仍可编辑，本次覆盖项只影响当前项目，更新库中风格需要明确保存。

### 风格文档记录什么

| 类别 | 可复用信息 |
| --- | --- |
| 封面 | 艺术字体、贴画、标题布局与颜色；具体标题由本次素材决定 |
| 开头 | 快剪总时长、每镜头停留时间、播放倍速、是否静音 |
| 正文 | 保留偏好、叙事顺序原则、哪些类型的片段适合加速 |
| 字幕与标注 | 字体、字号、安全区域、关键词强调和时间标注的表现方式 |
| 画面与声音 | 色彩、轻特效偏好、BGM 氛围与音量、人声与背景音乐的关系 |
| 时长与结尾 | 默认目标时长或保留比例、收尾方式 |

每份风格提供人能读懂的说明，并计划配套供系统应用的结构化设置。保存时记录风格格式版本、所用字体/音乐等资源标识和对应成片版本，便于后续检查兼容性。只应用当前系统支持的设置；封面、BGM 等尚未实现的能力继续显示为待支持。

**通用风格与本次剪辑指令分开**：“开头每镜头约 0.5 秒并静音”可复用；“删除 01:20–01:35”、素材文件名、具体对白、地点和日期属于本次项目，默认不写入可复用风格文档。新素材按风格重新选片和计算时间线，不照搬旧素材的时间点。参考 Shorts 用于形成可调整的风格草稿，不承诺逐帧复刻。

A 负责风格提取、设置合并与应用、存储和渲染兼容检查；B 负责风格文档预览、保存/导入入口与个人风格库页面。实现时先打通现有设置的保存与复用，再逐步接入新增的封面、音乐与特效能力。
