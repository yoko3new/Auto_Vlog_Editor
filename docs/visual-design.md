## 如何用少量时间让界面更有吸引力

<a id="s12-1"></a>

### 视觉方向：小型杂志编辑台

界面使用暖白背景、深色文字、少量陶土色点缀，配一个占据主要面积的视频预览。让用户首先看到视频和风格示例。

针对 Creative 赛道，封面旁可增加一行感受描述，例如 “Warm, playful, a little nostalgic”。情绪描述要与实际结果一致。作品预览和修改前后对比比技术参数更适合放在主要区域。

建议把界面打磨时间预算设为约 3–4 小时，作为范围控制目标，不是工时保证。先完成布局和状态，再加装饰。

<a id="s12-2"></a>

### 单页双栏布局

桌面主内容宽约 1120–1200px，左侧约三分之一，右侧约三分之二。窄屏自动上下排列。优先检查演示电脑和投影上的效果。

```text

Your day, beautifully cut.
Turn everyday clips into a film worth keeping.

│ 拖入素材 / 使用示例   │  │           大视频预览              │
│ [缩略图][缩略图]      │  │      开始前：标明示例的封面       │
│ 素材段数 · 总时长     │  │      完成后：真实成片播放器       │
│                      │  │                                    │
```

<a id="s12-3"></a>

### 一套可以直接采用的设计参数

| 项目 | 建议 |
| --- | --- |
| 页面背景 | `#F6F3EE` 暖白 |
| 内容卡片 | `#FFFEFA`，细边框 `#DED8CF` |
| 主要文字 | `#252522` |
| 次要文字 | `#68645E`，保持可读性 |
| 主按钮 | `#8F422D`，白色文字 |
| 正文字体 | Inter 或 DM Sans，二选一 |
| 大标题字体 | Playfair Display，少量使用 |
| 控件高度 | 约 44px，便于点击 |
| 圆角 | 卡片约 16px，按钮约 10px |
| 间距 | 以 8px 为单位：8、16、24、32 |
| 动画 | 只做轻微 hover、选中边框和淡入 |

将颜色、字体、圆角和间距集中成 CSS 变量，再用 Tailwind 排版。shadcn/ui 提供按钮、卡片、输入框等组件，官方有 Vite 安装路线；只加入页面需要的组件并锁定依赖。[官方 Vite 指南](https://ui.shadcn.com/docs/installation/vite)

这组颜色和间距是本项目的设计建议，可根据实际封面微调。不要把全部颜色都用成强调色。

<a id="s12-4"></a>

### 最值得花时间的六件事

1. **真实封面。** 每个风格使用实际渲染视频的封面，体现字体、构图和色彩；封面比抽象图标更能说明效果。
2. **大预览。** 成片始终占视觉中心。标题和字幕在正常播放尺寸下必须读得清。
3. **好看的初始状态。** 上传前显示一支明确标记的示例及“Try sample clips”，让用户知道最终能得到什么。
4. **收起不常用设置。** MVP 只展示固定风格和输出规格；V2 才显示已实现的情绪与时长选择。高级选项折叠，避免满屏参数。
5. **做好等待与结果。** 有阶段文案、有旧版本可看、有下载、有摘要；失败能恢复。
6. **统一对齐。** 字号、按钮高度、卡片边距、封面比例一致，删除多余说明文字和重复边框。

示例素材按钮复用真实流程。如果直接播放预生成视频，必须标注为示例；不要让用户误以为它是刚生成的结果。浏览器可能限制自动有声播放，演示脚本保留手动点击播放。

<a id="s12-5"></a>

### 前端组件怎么选

| 页面部分 | 实现建议 |
| --- | --- |
| 双栏布局 | CSS Grid；窄屏改为上下排列 |
| 上传区 | 原生文件输入 + 拖放；后端仍检查真实格式和体积 |
| 素材栏 | 缩略图网格 + 时长 Badge，不做可拖拽复杂时间线 |
| 风格卡 | 实际成片封面 + 单选状态；只显示能真正导出的风格 |
| 主预览 | 原生 `<video controls>`，固定比例，足够大 |
| 修改面板 | Textarea、Apply、Warmer；标题和删除可提供文字示例，不放未实现的操作按钮 |
| 版本与设置 | Select、Tabs 或折叠面板；高级选项默认收起 |
| 等待和错误 | 阶段列表、Skeleton、可重试提示，保留旧视频 |

用 React 的文本渲染展示用户和模型文字，不把这些内容直接拼成 HTML。

<a id="s12-6"></a>

### 用两个小时换明显的观感提升

先给 Replit Agent 一份具体视觉约束：“暖白纸张底色、黑色编辑式大标题、一种陶土色强调色、左侧素材与风格、右侧大视频预览、底部一句话修改；使用真实样片封面。只做这一屏的空白、处理中、完成和失败状态。”

建议投入：30 分钟统一布局和字体，30 分钟制作真实封面，30 分钟补齐四种状态，30 分钟检查播放、对齐和小屏幕。动画只做短淡入和按钮反馈；不要用大量漂浮卡片、装饰渐变和粒子背景挤压视频预览。

**网页上的 CSS 效果不会自动进入导出的 MP4。** 网页设计由 React 完成；视频里的标题、固定装饰和调色由 `titlecard` + FFmpeg 完成；字幕仅在 V2-3 加入。两边共用颜色和字体规范，分别验收。
