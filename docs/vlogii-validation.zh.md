- 未验证任何公开部署、Replit 存储、身份验证或杂志风格渲染；BGM 仅按“风格成片”一节所述验证。

- Windows 项目锁未实现。
- Gemini 接收代理视频进行视觉分析，并接收单独提取的原始音频进行语音识别。应用程序在识别后调用远程删除；提供方的保留策略不在本地验证范围内。

### 开头快剪默认静音

用户报告闪切开头中源语音被切碎。`Plan.mute_source_audio` 现出于兼容性考虑默认设为 false，而在快剪模式中设为 true；实际渲染映射静音音频而非源音频。该标志在时间/速度编辑和重试过程中持续存在；编辑历史精彩片段剪辑也会使用其保存的选择来应用该策略。正文模式保留自然音频。静音参与渲染缓存指纹计算，因此有声缓存片段不能复用为静音输出。

**95 项 Python 测试通过**，包括实际有声与静音导出对比、缓存分离、部分速度编辑保持静音以及撤销。TypeScript/Vite、Ruff 和文档检查通过。用户的同一套 14 镜头蒙太奇被重新渲染为 `projects/示例快剪20261010/cuts/cut_004/film.mp4`（4.667 秒时间线，4.688 秒容器）。将其音频解码为 PCM 验证了**峰值振幅为 0**，且完整视频/音频解码通过；旧的导出文件得以保留。日志与摘要：私有 `local-evidence/示例回归20261010/mute-tests.log`、`flash-muted-render.log`、`flash-muted-audio.log`、`flash-muted-summary.json`。无需新的 Gemini 请求。

用户认为 0.333 秒/2x 的闪切过快。第二轮对比使用了相同的 14 个入选时刻，以 1x 居中截取 0.5 秒源区间：`projects/示例快剪20261010/cuts/cut_005/film.mp4`，**7 秒时间线**，静音。完整解码及解码音频峰值 0 已验证；源文件和早先的剪辑保持保留。私人证据：`local-evidence/示例回归20261010/flash-balanced-summary.json`、`flash-balanced-render.log`、`flash-balanced-audio.log`。用户批准了这一节奏；当前默认值为每镜头 0.5 秒、1x、源音频静音，并带有可编辑控制项。
