## 按阶段验收、性能和风险

<a id="s15-1"></a>

### 最少验收案例

| 阶段 | 案例 | 通过标准 |
| --- | --- | --- |
| MVP 开工 | 两人接口与模块交接 | HTTP 样例、mock 与真实响应结构一致；同一份时间线可直接交给真实渲染器；模拟标记没有进入正式成功结果 |
| MVP 开工 | Replit 技术验证 | [开工验证：先确认 Replit 能跑通，再接 AI](deployment.md#s18-2) A、B、C 均有实际结果；九秒小样只验证环境，三十秒实际负载另验 |
| MVP 开工 | AI 理解与选片 | [AI 素材理解与选片测试：第 6–7 小时首测，第 14 小时前验证成片](ai-selection.md#s20-4)的人工标注与模型结果有对照记录；最终截取保留关键瞬间，无明显重复、误拍和编造事实，契约与素材边界检查通过 |
| MVP | 常规日常素材 | 生成约 30 秒开场速剪，有代表性瞬间与合理衔接，无大量重复，画面和 BGM 连续 |
| MVP | 改标题、调暖度 | 指定改动实际生效，其他镜头安排保持一致 |
| MVP | 删除素材 | 被删内容不回来，剩余画面连续；按[`config.json`：保存用户意图和版本设置](reference/timeline.md#s6-4)自然时长策略校验，不能被旧目标拒绝 |
| MVP | 修改失败、撤销后再修改 | 旧成片可播放，失败不谎报成功，历史版本不被覆盖 |
| MVP | 第二套素材 | 第 14–24 小时用未参与首轮调参的素材复查选片与成片，继续对照人工标注；不能仅对固定 Demo 样本有效 |
| MVP | 正式环境与恢复 | 正式链接上传、处理、播放、下载可用；关闭页面不取消任务；重启后能打开旧成功版本，中断任务可重试，失败不阻塞下一任务 |
| MVP | 有限格式组合 | 旋转信息、横竖混合、无音轨；原声均静音；不宣传未验证的 HDR/HEVC |
| V2-1 | 同素材两种情绪 | 画面风格、节奏与音乐有可感知差异，切点重算正确 |
| V2-2 | 30 秒缩到 20 秒 | 目标时长满足约定，片段合法，已删除素材不被补回 |
| V2-3 | 一段清晰短口播 | 整句保留、字幕同步、BGM 压低；不与旧功能冲突 |
| V3 | 逐项功能验证 | 竖屏主体可见、60 秒资源可承受、第二风格确实可导出；特效与参考图能力不夸大 |

MVP 对时间线做少量必要自动测试：素材越界、硬切累计时长、删除后重排；对状态做失败保留旧版与撤销测试。字幕映射在 V2-3 加测，转场重叠在 V3-3 加测。界面颜色和间距人工检查。

成片检查包括 FFmpeg 成功退出、ffprobe 读到有效视频流、分辨率和时长符合阶段契约；再人工看一遍并试听。能解码不等于剪得好。

### 90 秒挑战的示例预算

以下用于发现瓶颈，不是已测结果。素材上传完成后计时，模型已加载的运行与冷启动分别报告。

| 阶段 | 初始预算 |
| --- | --- |
| 读取、抽帧、音频提取 | 15 秒 |
| 内容分析（MVP 不调用 ASR） | 25 秒 |
| 导演规划与时间线计算 | 15 秒 |
| 规范化选中片段、渲染 | 30 秒 |
| 输出检查和返回 | 5 秒 |
| 总计 | 90 秒 |

每阶段记录实际耗时。一次 API 重试就可能打破预算；先知道慢在哪，再减少图片或调整编码；V2-3 才需要额外评估 ASR，不盲目增加并发。对同一输入至少完整测几次，并报告冷启动、首次处理、缓存修改的区别。

### 主要风险与对策

| 风险 | 做法 |
| --- | --- |
| 模块分别能跑，整体接不上 | 早期用同一份手工数据，按关卡真实联调 |
| 本地或 Preview 成功，正式部署失败 | 前 6 小时执行[开工验证：先确认 Replit 能跑通，再接 AI](deployment.md#s18-2)验证；分别检查发布配置、后台任务、存储恢复和实际负载，记录失败发生在哪一步 |
| AI 数据合法但故事不好 | 限制重复，按活动组织，真实观看和盲评 |
| 读不到拍摄时间 | 元数据 → 可解析文件名 → 上传顺序；标明来源 |
| 静态关键帧漏掉关键动作 | 给帧加时间，必要时增加采样，不让 AI 猜精确动作边界 |
| 字体或标题溢出 | 本地字体、短标题、文字测量和字号下限；渲染实际预览 |
| 转场和音频错位 | 最终时间线统一计算；优先硬切；音频按最终起点放置 |
| HDR、旋转、可变帧率导致异常 | 保留原件，规范化选中区间，保存转换日志 |
| 同时渲染导致机器卡死 | 生成与修改共用串行队列；限制 FFmpeg 和 ASR 的资源占用 |
| 网络或 API 不可用 | 明确标记的缓存、备用成片和完整录屏 |
| 文件泄露或 API key 出现在页面 | API key 仅后端环境变量；仅返回需要展示的输出文件 |

调用 FFmpeg 使用参数列表和 `shell=False`，不要拼接用户文字成 shell 命令。ASS 等格式的文本还要做对应转义。

媒体接口只接受内部项目/版本 ID，经检查后映射到文件；不接受任意磁盘路径。前端静态目录仅放页面资源，API key、原始素材和日志不能一起公开。
