# 保留比例、开头快剪与按时间修改

[返回总览](../README.md) · [现行 API](vlogii.openapi.json) · [Vlogii 指南](vlogii-guide.md)

## 四种生成模式

| 页面选项 / API `mode` | 行为 | 留空目标时长 |
| --- | --- | --- |
| AI 自动 / `auto` | 根据素材、口播和用户描述选择内容与顺序 | AI 决定，不再默认 30 秒 |
| 开头快剪 / `highlights` | 独立的开头精华画面集合，短镜头硬切；单镜头默认最多约 0.5 秒，可调 | 约 5 秒；素材不足不重复补足 |
| 保留大部分 / `keep_most` | 按导入顺序保留；去黑场，修剪有口播素材中至少 3 秒的无语音间隙；句子前后各留约 0.35 秒 | 按保留下来的内容决定；不接受目标时长 |
| 完整保留 / `keep_all` | 按导入顺序保留所有已导入素材，不做 AI 选片 | 与素材总长接近，只受逐段帧取整影响；不接受目标时长 |

完整保留与保留大部分不调用 AI 做剪辑决策；仍复用或运行原声转录来生成字幕。重复文件在导入时已去重，“全部”指已导入素材集合。CLI 按文件名排序，网页按上传顺序导入，不推断拍摄时间；后续删除只改新版本，不修改原文件。

保留大部分默认留下无口播风景镜头。勾选“同时删除所有没有识别到语音的区间”，或输入“没有语音的都删掉”，会去掉这些镜头；“无语音”依据识别时间戳，不是静音检测，漏识别可能使内容被删，需看成片确认。黑场检测为连续至少 0.3 秒、约 98% 像素低于阈值的黑画面；有代理时复用代理，时间精度受代理采样限制。

AI 自动 / 快剪接受可选 `target_seconds`，范围 1–1800 秒；也可输入“保留约2分钟”。时长是近似目标，不保证精确、不重复素材凑时长。完整保留不能同时指定“30秒”，冲突会提示改选模式或清空时长。

## 输入示例与优先级

生成描述旁可点击示例，保留自写文字并同步对应模式；切换时替换上一条模式示例，避免冲突，不自动提交。中英文示例包括：

- “全部保留，按素材顺序” → 完整保留。
- “保留大部分内容” → 保留大部分。
- “没有语音的都删掉” → 保留大部分，并启用去无语音区间。
- “生成5秒的开头精华快剪” → 快剪。
- “保留约2分钟，口播尽量完整” → AI 自动，目标约 120 秒。

明确选择的非自动模式与填写的目标秒数优先于文字；AI 自动下识别常见保留/快剪表达与数字时长。其余创作描述交给 AI 自动/快剪计划使用。保留模式是固定保留规则，不支持任意语义选片；要改变选片顺序或按事件选择，使用 AI 自动。快剪目前单独导出，不自动附加到完整版；BGM 与节拍卡点未接入。

用户在真实样片对比后认可 **0.5 秒一镜、1 倍速、静音**，现作为默认快剪节奏；仍可调整更快或更慢。

## 视频速度与闪切节奏

生成增加 `speed`（相对原素材 0.25–8 倍，默认 1）与 `shot_seconds`（快剪单镜头播放上限 0.15–1 秒，默认 0.5）。网页提供速度单选栏 0.5 / 1 / 1.5 / 2 / 4 / 8 倍；快剪提供 0.25 / 0.35 / 0.5 / 0.8 秒节奏选项。目标秒数、镜头停留均按**最终播放时间**计算。快剪开头默认静音，不叠口播字幕/文字，避免短镜头把人声切碎；正文保留原声和字幕。静音状态保存在计划的 `mute_source_audio`，调速、删除、Retry 后仍保持静音，旧成功文件保留。当前不添加 BGM。完整保留在倍速下仍保留全部区间，时长按速度变化。

编辑 `speed` 可空：null 保持各段现有速度；传 1 恢复原速。`speed_ranges: [{"start": 12, "end": 18, "speed": 2}]` 设置对应范围的绝对倍速，区间覆盖同时指定的整片速度，不累计乘速。时间段指令例如“00:12到00:18加速到2倍”或 `speed up 00:12 to 00:18 to 2x`；分号可连接删除和调速。速度区间不能重叠；越界、短于一输出帧或映射不足一素材帧均拒绝。

代码按帧计算播放时长和素材映射，字幕与文字随速度缩放；FFmpeg 使用视频时间戳与音频 tempo 调整，保留音调（不承诺极端倍速的听感质量）。无原声素材补静音，不对静音执行变速。慢速重复帧而非 AI 插帧。实现依据：[FFmpeg Filters](https://ffmpeg.org/ffmpeg-filters.html#atempo)。

## 对当前成片按时间删除

编辑字段增加 `remove_ranges: [{"start": 12, "end": 18}]`（秒）和可选 `instruction`；网页有输入框和可点击示例，CLI 可用 `--remove-ranges`。例如“删掉00:12到00:18，1分到1分8秒不用”或 `delete 00:12 to 00:18`。

时间指**当前成功成片**的播放位置。支持 `mm:ss`、`hh:mm:ss`、小数秒、`1分8秒`，以及多个区间；也支持上述明确倍速指令，不支持任意自然语言操作。包含“加BGM”等未支持操作时拒绝整个指令，不静默执行部分修改。区间越界、反向、少于一帧、删除全片均拒绝；重叠区间合并后按帧映射回原素材。删除、调速与排除素材同时提交时，所有时间坐标先取同一当前成片，再完成删除/调速并排除素材。

每次修改保存新计划与时间线，重新映射字幕/文字并导出新版本；失败保留旧片，Retry 保留原区间与原版本，Undo 恢复旧版。对白在删除点可能被截断，需选择合适句子边界。

```sh
uv run vlogii run my-day --mode keep_all
uv run vlogii run my-day --mode keep_most --remove-no-speech
uv run vlogii run my-day --mode highlights --seconds 5 --shot-seconds 0.5 --speed 1
uv run vlogii run my-day --direction "保留约2分钟，口播尽量完整"
uv run vlogii edit my-day --remove-ranges "删掉00:12到00:18"
uv run vlogii edit my-day --instruction "00:12到00:18加速到2倍"
uv run vlogii edit my-day --speed 1
```

## 兼容与验证

旧请求仍可显式提交 `target_seconds: 30`，旧成功版本继续播放与撤销。旧计划缺少 `speed/captions` 默认原速且显示字幕；已有成功文件不重写。新计划按素材区间保存速度，时间线增加 `source_frames/speed`。**省略目标时长由默认 30 秒改为 AI 决定**，依赖旧默认的调用方应明确传 30；旧 Retry 保存的 30 不变。生成 checkpoint 增加模式与规则版本，模式变化会重做计划，仍复用识别缓存。每个新成片保留 `selection.json`，项目响应增加可空的 `selection`；旧版本没有该文件时返回 null。

自动检查涵盖模式/时长优先级、完整保留、去黑场与停顿、快剪镜头约束、跨片段删除与字幕/文字时间映射、越界/不支持指令拒绝、失败重试与旧版本保留。真实 FFmpeg 测试验证全保留、黑场删除、按帧删除与撤销；网页操作和真实素材结果见[本地验证](vlogii-validation.md)。
