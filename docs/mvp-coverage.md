## 当前已经覆盖

| 功能 | 实际行为与边界 | 实现 / 已有验证记录 |
| --- | --- | --- |
| 真实素材导入 | MP4/MOV/M4V/MKV；批量上传、读取时长/尺寸/帧率/音轨/色彩、散列去重；页面列文件名和时长，没有缩略图 | [API](../src/vlogii/api.py)、[媒体](../src/vlogii/media.py)；真实 HTTP 上传有记录，浏览器选文件控件未自动验收 |
| Gemini 视频理解 | 低分辨率代理视频用于事件/亮点分析，原声独立转录并保留源语言；两类分析分别缓存 | [AI](../src/vlogii/ai.py)、[流水线](../src/vlogii/pipeline.py)；两套各三段真实手机素材有记录，未做选片质量基准测试 |
| AI 剪辑计划 | 接收创作方向和目标时长，选区间、排序、生成标题和少量文字；计划不合法时校验并尝试修正 | [AI](../src/vlogii/ai.py)；生成前方向描述可选；支持常见模式/时长与成片时间删除/调速表达，任意语义编辑未实现 |
| 确定性时间线 | Python 校验素材引用、区间和文字，按整数帧计算时长并重映射字幕 | [时间线](../src/vlogii/timeline.py)、[测试](../tests/test_core.py) |
| 真实 MP4 渲染 | FFmpeg 硬切、画面等比缩放补黑边、普通模式保留原声，无音轨补静音；快剪默认静音且不叠口播字幕；烧录文字/字幕，检查输出规格并全片解码 | [渲染](../src/vlogii/render.py)、[媒体测试](../tests/test_media.py) |
| 横竖屏与色彩 | 网页可选 9:16 / 16:9，默认竖屏 1080×1920、30 fps、SDR/H.264/AAC；全 HLG 素材可选保留 10-bit HEVC，混合素材转 SDR | [模型](../src/vlogii/models.py)、[API](../src/vlogii/api.py)；竖屏/SDR/全 HLG 有记录，HEVC 浏览器播放取决于环境 |
| 标题、暖度、排除素材 | 输入新标题、勾选变暖、按文件选择排除素材；重新渲染，复用已有计划、不再调用 AI | [编辑逻辑](../src/vlogii/pipeline.py)、[前端](../frontend/src/main.tsx)；三项操作有浏览器验证记录 |
| 版本与撤销 | 成功输出保存独立版本；失败保留旧成片；撤销回到上一成功版本，无需 AI 或重渲染 | [流水线](../src/vlogii/pipeline.py)、[渲染](../src/vlogii/render.py)；没有任意历史版本选择 UI 或重做入口 |
| 页面闭环 | 拖入/选择文件、项目列表、方向输入、生成、实际阶段轮询、播放器、错误提示、编辑、撤销、下载 | [前端](../frontend/src/main.tsx)；构建和主要浏览器操作有记录，移动端/完整端到端测试未记录 |
| 本地任务与恢复 | 单 worker、队列上限 8、同项目防重复运行、JSON 持久记录；重启把未完任务标为失败，可点击 Retry 复用原请求和有效成果；旧成功视频继续可读 | [API](../src/vlogii/api.py)、[存储](../src/vlogii/storage.py)、[API 测试](../tests/test_api.py)；没有旧契约中的 request_id 幂等和 base_version_id 检查 |
| 播放、下载与诊断 | MP4 播放/字节范围响应/附件下载；记录完整 FFmpeg 日志与 verification.json；CLI 与网页共用核心 | [API](../src/vlogii/api.py)、[CLI](../src/vlogii/cli.py)；重启后播放和 HTTP 206 下载有记录 |

输入限制：最多 50 段，单文件 512 MiB、单次上传 2 GiB、总素材 30 分钟。AI 自动/快剪的目标可留空或指定 1–1800 秒；保留模式按内容决定时长，不接受目标。时长是规划偏好，不保证精确，也不重复素材凑时长。快剪默认目标约 5 秒，每镜头约 0.5 秒、1 倍速、静音，并单独导出。支持整片速度与当前成片范围删除/调速、输入示例；完整规则见 [剪辑模式](editing-modes.md)。真实完整保留样片为 195.5 秒/21 段，认可的节奏样片为 7 秒/14 镜头；7 秒是该样片目标，不是默认总长。

## 对照原比赛 MVP，还差什么

| 原比赛目标 | 当前覆盖 | 剩余工作 |
| --- | --- | --- |
| 上传与素材展示 | 部分覆盖 | 缩略图、方向展示及比赛素材集验收 |
| AI 理解/选片/排序 | 主链路已有 | 带人工标注的关键瞬间、重复镜头和内容质量评估 |
| 固定杂志风成片 | 尚未覆盖 | 设计并渲染固定标题层次、装饰和统一视觉；网页审美不等于 MP4 风格 |
| 固定 BGM 与节拍剪辑 | 部分覆盖 | 已内置 6 首 CC0 音乐、连续混音与口播压低；节拍数据与时间线卡点待实现，见[资源说明](free-resources.md) |
| 首次 30±1 秒、720p/16:9/30 fps | 部分覆盖 | 当前规格可配置、网页默认 1080p 竖屏；30 秒仅为目标，需验证满足比赛时长与规格 |
| 三类自然语言修改 | 控件形式已有 | 任意语义操作的解析、歧义确认与摘要；当前支持字段/文件 ID 操作及受控时间删除/调速表达 |
| 版本/撤销/失败保护 | 主要行为已有 | 撤销后继续修改等完整场景复测；不要宣称已支持旧 API 全部版本与幂等语义 |
| 完整单页交互 | 基础页面已有 | 队友负责前端完善和真实 API 联调；不展示尚未实现的入口 |
| Replit 正式部署/持久恢复 | 尚未覆盖 | 云端存储、正式部署、真实负载与重启恢复验收；当前仅本地文件保存 |

原[产品定义](product.md)继续作为比赛目标。当前已具备原声字幕、竖屏和 HDR 等能力，不代表原 V2/V3 整个阶段完成：例如字幕和 BGM 压低已有，节拍卡点尚无。是否改变比赛范围需另行明确，本页只记录实际覆盖，不把后续方案当作已实现。

## 验证结论怎么读

`ec21851` 随附记录为 29 个 Python 测试通过、0 跳过，并有真实 Gemini、FFmpeg、浏览器与恢复小样。本轮体验修复另有 44 项测试、真实横竖屏字幕输出与网页编辑 Retry 验证，并在本地密钥配置后跑通两款新 Gemini 模型的单素材真实闭环；识别准确率仍未做人工对照。最新剪辑模式/速度发布有 95 项测试通过、真实完整保留和静音快剪样片，以及网页调速/恢复原速/撤销记录。Linux CI、正式部署、编辑质量基准和性能目标均未确认。详见 [修复记录](mvp-fixes.md)和 [验证](vlogii-validation.zh.md)。
