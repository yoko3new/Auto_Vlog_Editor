## 赛前准备

先确认比赛对既有代码和预制资产的要求，按规则准备。以下是建议清单，不代表已经完成。

- [ ] 确认 36 小时安排、现场展示时长、代码与资产规则。
- [ ] MVP 主素材 10–15 段，以及一套内容不同的备用素材；都在输入边界内。
- [ ] 从主素材中选 10 段作为 AI 选片测试集，准备[AI 素材理解与选片测试：第 6–7 小时首测，第 14 小时前验证成片](ai-selection.md#s20-4)的人工标注；覆盖相似镜头、短暂动作、有意义但角度欠佳的画面，以及明显误拍。备用素材留作第二套复查，不用于首轮调参。
- [ ] 只有准备进入 V2-3 时才增加一段清晰短口播测试素材。
- [ ] MVP 一首许可适合演示的固定 BGM，保存许可记录、标好节拍；V2-1 再加第二首。
- [ ] 先下载实际使用的 2–4 个字体，保存相应许可文件。
- [ ] 一份经过真实素材测试的调色配置；没有合适 LUT 时先用简单调色。
- [ ] 准备 Replit 账号、可用部署资源与预算；按比赛规则允许的时间执行[开工验证：先确认 Replit 能跑通，再接 AI](deployment.md#s18-2)关卡 A，锁定 Node、Python、FFmpeg 和字体版本。
- [ ] 将[开工验证：先确认 Replit 能跑通，再接 AI](deployment.md#s18-2)关卡 B、C 放入前 6 小时工作清单，准备记录实际结果；赛前未获准实施的部分留到比赛开始后完成。
- [ ] 将[AI 素材理解与选片测试：第 6–7 小时首测，第 14 小时前验证成片](ai-selection.md#s20-4)首轮测试放在 Replit 验证之后的第 6–7 小时；提前准备一家可用的 AI API、后端密钥配置方式和调用用量记录，模型尚未实测时不写成已选定。
- [ ] MVP 验证标题图层、字体、硬切与调色；字幕和溶解在相应阶段开始前另验。
- [ ] 选定的主 AI API 在演示网络可用，配置超时与有限重试。
- [ ] Gemini / ElevenLabs 仅在小样本表现或接入便利性合适时采用；若兼报奖项，再核对实际 API 使用和提交要求。
- [ ] 用实际成片生成风格封面，准备界面初始示例。
- [ ] 准备手工计划、最终时间线和三个镜头的小型联调样本。
- [ ] 保存完整演示录屏与各步备用 MP4，清楚标注缓存或预生成内容。

## 三分钟 Demo 与 pitch

开场可以用：“Your camera roll remembers what happened. We help you express how it felt.” 随后通过成片证明这一承诺。先让观众看见和感受到变化，再用简短说明解释如何实现。

| 时长 | 内容 | 重点 |
| --- | --- | --- |
| 0:00–0:20 | 展示一屏未剪的生活素材 | “这些是我一天拍的片段，我想把那天的感觉留下来。” |
| 0:20–0:40 | 上传、展示固定风格、开始生成 | 让评委看懂操作有多简单 |
| 0:40–1:10 | 处理期间解释想表达的故事和感觉 | 结合少量原素材，解释为何保留某个瞬间；显示真实阶段 |
| 1:10–1:35 | 播放 15–25 秒成片 | 给画面和音乐留出完整播放时间，避免一直说话覆盖作品 |
| 1:35–2:15 | 一句修改，展示前后对比 | MVP 演示改标题或删除素材，并撤销；只有 V2-1 验收后才展示情绪切换 |
| 2:15–2:35 | 说明个人创作空间 | 用户怎样控制自己的故事；说明风格来自人工设计、内容适配来自素材分析 |
| 2:35–2:50 | 一张架构图与一组实测数字 | AI 计划、确定性时间线、渲染执行，说明计时口径 |
| 2:50–3:00 | 收尾 | “Turn everyday clips into a film that feels like you.” |

现场脚本必须按实测重排。如果首次生成耗时接近 90 秒，再加修改渲染就很难放进三分钟；可先播放明确标记的预生成主样片，再现场演示一次修改，或把完整生成过程放在录屏中展示。

不要把“Vertical”写进正式脚本，除非它已经实现并在演示素材上验证过。

若 V2-1 已完成并演示两种情绪，用同一份原素材，各播放约 8–10 秒的可比段落。让观众看清音乐、节奏或构图如何改变表达；修改只有颜色时就如实描述为颜色变化。准备好一组真正有区别的结果，再决定是否把它作为主要亮点。

可能的问题：

- **和 CapCut 的区别？** 现有工具也能自动剪辑；本项目专注这类生活素材的内容组织、可控风格和一句话修改，并用同素材对比验证效果。
- **是不是每个人都长得一样？** 风格提供一致的视觉语言，选片、活动顺序、文案与点缀色来自用户素材；还需要真实测试是否足够个性化。
- **AI 出错怎么办？** 格式校验、业务检查、有限重试和规则降级；旧版本保留，用户可撤销。
- **为什么没有数据库？** MVP 是单实例受控演示，用项目 JSON 管理记录、对象存储保存媒体；多用户需求出现后再迁移。
- **为什么属于 Creative 赛道？** 它让用户用自己的生活素材表达想保留的感受；用户可以参与内容和风格决定，现场展示实际创作变化。
