## Font and music candidates

[Research and integration plan](../docs/free-resources.en.md) · [Candidate catalog](candidates.json)

This catalog records downloaded public font/music candidates and content hashes. Binary downloads remain in the ignored local evidence directory pending application packaging. It is not a runtime preset registry.

The original Noto font licenses are retained in `licenses/`. Holizna's source collection labels its music CC0; source URLs, authors, file hashes and validation are recorded in the catalog and research document. No user's uploaded assets, private footage or API credentials belong here.
